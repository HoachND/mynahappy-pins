# mynahappy-pins

Kho ảnh pin cho Pinterest của shop **Myna Happy** (printable coloring pages).

Repo này chỉ để **host ảnh** — Pinterest tải ảnh về qua `raw.githubusercontent.com`,
nên repo bắt buộc phải ở chế độ **public**. Không có mã nguồn, không có dữ liệu riêng.

- `pins/` — 414 ảnh 1000x1500 PNG (tỉ lệ 2:3 chuẩn Pinterest)
- Dạng URL: `https://raw.githubusercontent.com/HoachND/mynahappy-pins/main/pins/<tên file>.png`

Ảnh sinh bằng `vimai_pinterest_pins.py`. Bản quyền tranh thuộc Myna Happy.
